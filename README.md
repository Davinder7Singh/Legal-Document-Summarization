# Legal-Document-Summarization

# Project Objective:<br>
Goal:<br>
To automatically summarize lengthy legal documents such as NDAs, SLAs, or Distributor Agreements using AI.<br>
Purpose:<br>
Help lawyers quickly review key clauses (like Confidentiality, Termination, Governing Law).<br>
Compare extractive vs. abstractive summaries.<br>
Evaluate how well AI can preserve legal meaning and structure<br>
